# Changelog

All notable changes to the Spark Performance Optimization extension are documented here.

## 0.1.2

- Fixed **Spark Perf: Open CLI Terminal** command invocation in PowerShell.

## 0.1.1

- Added step-by-step instructions for local analysis, the guided Copilot skill, and CLI usage.
- Added copyable single-run and baseline-versus-candidate analyzer examples.
- Opened the CLI terminal in the installed skill directory so documented commands run as written.
- Updated the Marketplace icon to the required 128 by 128 PNG size.

## 0.1.0

- Added local analysis for raw, gzip, and ZIP Spark event logs.
- Added commands to install, update, and uninstall the bundled Copilot skill.
- Added a CLI terminal command for the complete analyzer command surface.
- Added atomic skill installation with ownership validation.
- Added archive safety limits and cancellation support.
- Added sanitized performance methodology, report templates, and JSON-driven PowerPoint generation.
