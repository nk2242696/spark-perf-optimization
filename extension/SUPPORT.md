# Support

Use GitHub Issues for reproducible bugs and feature requests:

https://github.com/nk2242696/spark-perf-optimization/issues

Include:

- VS Code and extension versions
- Operating system
- Python version and configured `sparkPerf.pythonPath`, if any
- The command used
- Sanitized output or error text

Do not attach raw Spark event logs unless you have reviewed and approved their contents. Remove application names, storage paths, SQL literals, user identifiers, tokens, and organization-specific metadata from reports and examples.

This community project does not provide an SLA. For a suspected security issue, do not open a public issue; use the private security-reporting mechanism on the GitHub repository once enabled.
